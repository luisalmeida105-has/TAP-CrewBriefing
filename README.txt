CrewBrief V1 — Instalação iPhone/iPad

1. Descompactar o ZIP.
2. Carregar TODOS os ficheiros desta pasta para a raiz do repositório GitHub Pages, substituindo os anteriores.
3. Verificar em Settings > Pages que a branch main e / (root) estão selecionadas.
4. Abrir o endereço GitHub Pages no Safari.
5. Tocar em Partilhar > Adicionar ao ecrã principal > Adicionar.
6. Abrir pelo ícone CrewBrief, não pelo separador do Safari.

A aplicação funciona em ecrã independente depois de instalada. A leitura OCR da fotografia e extração do PDF necessitam de ligação à internet na primeira utilização para carregar bibliotecas externas. Os ficheiros não são enviados a servidores do desenvolvedor. Confirmar sempre todos os dados. Não é app nativa App Store.
